# FeqhMuseWeb — میز داوری اجتهاد

وب‌اپ تعاملی فارسی و راست‌به‌چپ برای بررسی علمی ۱۰ قاعدهٔ پیشنهادی روش اجتهادی شیخ انصاری. فایل‌های سایت از پروژه [Feqh-Muse، PR #10](https://github.com/soltan-developer/feqh-muse/pull/10) به این مخزن انتقال یافته‌اند.

## قابلیت‌ها
- بررسی ۱۰ پرونده و ۶ جزء هر قاعده همراه با ۳۴ شاهد کانونی و سیاق آنها
- تصمیم **تأیید، رد، اصلاح یا تعلیق** با استدلال جزءبه‌جزء
- ذخیره محلی در مرورگر، نمایش پیشرفت، خروجی JSON/Markdown و ورود مجدد JSON
- رابط واکنش‌گرای فارسی، تم روشن و تاریک، بدون سرور یا کلید API

## فعال‌سازی سایت در GitHub Pages

در همین مخزن به **Settings → Pages → Build and deployment** بروید. گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب و **Save** کنید.

پس از موفقیت انتشار، نشانی سایت معمولاً این خواهد بود:

https://soltan-developer.github.io/FeqhMuseWeb/

**صرف وجود کد در مخزن به معنی انتشار Pages نیست.** این آدرس را پس از فعال‌سازی و موفقیت انتشار بررسی کنید.

## کار با سایت
۱. نام پژوهشگر را وارد کنید.
۲. پرونده قاعده را انتخاب و متن عربی و شواهد را بررسی کنید.
۳. برای هر شش جزء نظر بدهید و درباره کل قاعده دلیل نهایی بنویسید.
۴. «ثبت و تأیید ثبت نظر این پرونده» را بزنید.
۵. در انتها گزارش **JSON** را دریافت و در گفت‌وگوی ChatGPT پیوست کنید تا مراحل بعد پروژه براساس نظر شما پیش برود.

**ارسال مستقیم وجود ندارد.** داده‌های داوری فقط در `localStorage` مرورگر ذخیره می‌شوند و با دریافت فایل منتقل می‌شوند.

## اجرای محلی و تست
```bash
python -m http.server 8080
node --check app.js
node tests/smoke.mjs
```

سپس http://localhost:8080 را باز کنید.

## وضعیت علمی و انتشار

این ابزار داوری شخصی پژوهشگر اصلی است، نه داوری مستقل خارجی. هیچ قاعده‌ای با رأی کاربر به‌صورت خودکار در موتور تاریخی تأیید یا اجرا نمی‌شود. چاپ منابع هنوز تأیید نشده است.

**هشدار: این مخزن عمومی است.** `data/review-data.json` حاوی نقل‌هایی از منابع کتابی و متن برخی پرونده‌های پژوهشی است که به‌صورت عمومی قابل مشاهده‌اند. قبل از انتشار گسترده یا افزودن داده‌های بیشتر، ملاحظات حق نشر و محرمانگی را بررسی کنید. یادداشت‌های ذخیره‌شده در مرورگر رمزنگاری نشده‌اند.
